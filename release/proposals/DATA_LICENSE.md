# Proposed data notice — not yet adopted

Subject to the owner's confirmation of rights and approval, original CoPuzzle
generated datasets, annotations and result tables would be released under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The [legal code](https://creativecommons.org/licenses/by/4.0/legalcode.en) controls.

Proposed attribution: “CoPuzzle contributors, CoPuzzle rule-composition benchmark
v1”, together with the project URL, artifact/version identifier and a link to the
license. Indicate changes when redistributing modified material. A formal paper
citation, once available, is recommended as scholarly credit rather than an
additional restriction invented by this notice.

This proposal covers only the project's own rights. Third-party code, robot
models, meshes and other assets retain their original licenses and notices.
No endorsement by third-party authors or an institution is implied.
